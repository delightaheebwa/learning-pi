# Euler's number e

\(e\) is the special base for which the exponential function equals its own derivative:

- \(\frac{d}{dt} e^t = e^t\)

## Why it is special

For any base \(a\),

- \(\frac{d}{dt} a^t = \ln(a)\,a^t\)

So the derivative constant is \(\ln(a)\). The base \(e\) is the unique choice where \(\ln(e) = 1\), which makes the constant especially clean.

That is why writing exponentials in base \(e\) gives a very readable meaning to the exponent and the derivative.

## Connection to logs

Any exponential base can be converted to base \(e\):

- \(a^t = e^{\ln(a)t}\)

This is why [[Natural logarithm]] appears whenever exponentials are differentiated.
