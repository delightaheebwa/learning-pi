## Extracted notes

- For a scalar function of two variables, the total differential is
  - \(dF = F_x\,dx + F_y\,dy\)
- If you stay on a level set \(F(x,y)=c\), then the value does not change, so \(dF=0\) along the curve.
- For the circle-like example
  - \(S(x,y)=x^2+y^2\)
  - the screenshot shows \(dS = 2x\,dx + 2y\,dy = 0\)
- That same idea gives implicit differentiation rules for equations where \(y\) is not isolated.
- In the example
  - \(\sin(x) y^2 = x\)
  - differentiating both sides gives
    - \(\sin(x)(2y\,dy) + y^2(\cos(x)\,dx) = dx\)
- For the logarithm example, starting from
  - \(e^y = x\)
  - differentiating with respect to \(x\) gives
    - \(\frac{dy}{dx} = \frac{d(\ln(x))}{dx}\)
    - and the result is \(\frac{dy}{dx} = \frac{1}{x}\)
- The screenshots connect implicit differentiation to the inverse relationship between \(e^y\) and \(\ln(x)\).
