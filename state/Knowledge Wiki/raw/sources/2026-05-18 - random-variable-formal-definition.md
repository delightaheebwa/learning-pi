# Random variable formal definition

## Raw source

In this book, we refer to T as the target space and refer to elements of T as states. We introduce a target space function X : Ω → T that takes an element of Ω (an outcome) and returns a particular quantity of interest x, a value in T. This association/mapping from Ω to T is called a random variable.

## Extracted ideas

- Ω is the sample space (set of all possible outcomes)
- T is the target space (the space of values the random variable can take)
- Elements of T are called states
- X : Ω → T maps outcomes to values in the target space
- A random variable is this mapping/function, not the value itself
