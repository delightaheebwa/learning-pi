- **Formal statement delivered (fact-check 5/5, muse-spark verifier — this was the last successful muse-spark dispatch):** nonnegativity is a real theorem — **Gibbs' inequality**: for any two distributions Q, P over the same outcome space, Σ_i Q_i·log(Q_i/P_i) ≥ 0, equality iff P = Q; KL *is* that sum. One-line **Jensen** proof: log concave → Σ Q_i log(P_i/Q_i) ≤ log(Σ Q_i·P_i/Q_i) = log Σ P_i = log 1 = 0; negate. **Coding reductio** = the information-theoretic reading (negative KL ⇒ a code beating the truth's own optimal code ⇒ impossible). Scope: any two distributions over the same outcome space (finite or continuous densities). Consequences in lesson letters: H(P,Q) = H(Q) + KL(Q∥P) ≥ H(Q); MI = KL(joint ∥ product-of-marginals) inherits ≥ 0 for free.

- **Learner follow-ups (each a claims turn, fact-checked):**
  1. *Jensen vs Gibbs — who did what:* **Jensen** (Johan Jensen, Danish, published 1906) = the general concave-function tool: f(Σ w_i x_i) ≥ Σ w_i f(x_i), equality iff all x_i equal (strictly concave). **Gibbs** (Josiah Willard Gibbs, the inequality appears in his 1902 statistical-mechanics work) = the specific distribution statement Σ p_i log(p_i/q_i) ≥ 0, equality iff p = q. **"Gibbs is the what, Jensen is the how."**
  2. *"Negate both sides" =* multiply the whole inequality by −1 (arithmetic negation, not logical), flipping ≤ → ≥; the negated left side IS the KL sum because log(a/b) = −log(b/a) term-wise.
  3. *Why concavity ⇒ "function of average ≥ average of function values":* concave = curve above its chords (definition, said twice); the average-of-function point sits exactly ON the chord at the mixed input while the function-of-average point sits on the curve; numeric feel: log2 between 1 and 9 at equal weights → f(5) = 2.32 ≥ 1.585 = ½(0 + 3.17). In the proof this does one job: swap "average then function" for "function of average" — and the function of that particular average is log 1 = 0, a number we know. (Fact-check 5/5 on deepseek-v4.1-flash, after the outage.)

Rule to carry: **the weights are always the truth Q; the numerator tells you which direction the sum points** (Q-on-top = KL ≥ 0; P-on-top = the Jensen-friendly twin ≤ 0).
