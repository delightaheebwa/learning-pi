**Q:** When would you reach for `jq` instead of `grep` when extracting data from a JSON API response? What does `jq` give you that `grep` fundamentally can't?

**A (user):** grep can only match patterns in text; jq goes further — it can get different sections, keys, values of the JSON.

**Evaluation:** Pass. grep treats JSON as opaque text (can't distinguish key from value; breaks on minified vs pretty-printed). jq parses structure: navigates nested keys, filters arrays, transforms output.
