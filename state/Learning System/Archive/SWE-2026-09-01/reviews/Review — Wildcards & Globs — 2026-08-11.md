# Review — Wildcards & Globs — 2026-08-11

**Track:** SWE (Shell & Terminal)
**Question Type:** definitional
**Interval:** 7d → 14d (advanced)

**Question:** Fill the blanks: `?` matches exactly ___ character(s); `*` matches ___. `file_{draft,final}.txt` — braces generate both names whether or not those files exist, or match only existing files?

**Answer:** `?` = exactly one character; `*` = zero or more. Braces = brace expansion — generates both names regardless of existence (unlike wildcards, which match existing files).

**Assessment:** Correct on both parts.
