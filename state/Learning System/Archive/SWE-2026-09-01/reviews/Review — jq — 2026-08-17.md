**Question:** Name the three things `jq .` does for you, and give a jq filter that prints the `name` of every object in an array whose `version` is greater than 6. Then: what does `-r` change about the output?

**Answer:** `jq .` gets all JSON fields/files. The filter is `jq print(name) "version" > 6`. `-r` is for recursive — recursively finding all files that match the filter.

**Assessment:** ❌ Reset. 1) `jq .` **pretty-prints the JSON** so you can inspect structure (and acts as a validity check — invalid JSON errors out); it doesn't "get all fields". 2) The filter must be `.[] | select(.version > 6) | .name` — unroll the array → filter objects → extract the field; there is no `print()` in jq. Hard rule: keep the whole filter inside **single quotes** so bash doesn't try to run `.name`/`select` as commands. 3) `-r` is **not recursive** — it's **raw output**: strips JSON quotes so strings can be piped onward (`curl ... | jq -r '.name' | grep ...`).
