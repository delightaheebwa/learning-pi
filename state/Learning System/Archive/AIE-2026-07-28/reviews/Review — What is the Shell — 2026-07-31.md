## Question

What distinguishes the shell from the terminal emulator?

## Answer

The shell is the program that actually executes commands (the engine). The terminal emulator is the graphical window that communicates with the shell and displays its output.

## Assessment

✅ Correct. Clear distinction between execution layer and display layer. Good mental model.
