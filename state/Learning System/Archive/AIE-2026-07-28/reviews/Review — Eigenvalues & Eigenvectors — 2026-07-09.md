# Review — Eigenvalues & Eigenvectors

**Date:** 2026-07-09

**Track:** AI Engineering (aie)

## Question
In one sentence, what's special about an eigenvector?

## Response
When a certain matrix is applied to an eigenvector, the only way that matrix can transform that vector is by scaling it along the direction it is already in.

## Evaluation
**Correct.** Captures the core insight precisely: eigenvectors are directions that are only scaled, never rotated, by the matrix. A @ v = λ · v — the matrix doesn't change the vector's direction, only its magnitude.
