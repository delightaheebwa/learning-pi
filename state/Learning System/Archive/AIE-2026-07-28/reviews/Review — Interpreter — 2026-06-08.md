## Retrieval Question
How does an interpreter work, and what's the key difference from a compiler?

## User Response
Real-time translator — reads source code one line at a time and executes one line at a time. Uses precompiled C functions that know how to execute the source. Key difference: compiler does everything at build time, interpreter does it at run time.

## Evaluation
Correct. "Real-time translator" analogy and the precompiled C functions point are both solid. Core build-time vs run-time distinction captured.
