## Concept
Dev vs Production workflow

## Question Asked
"Why do we use an interpreter during development but a compiler for production?"

## User's Answer
Compiler enables optimization and faster runtime but takes longer for developer feedback; interpreter is slower at runtime but gives quick feedback per line of code.

## Evaluation
**Result: Advanced to 7d (next: 2026-06-09)**

Correct. User clearly articulated the tradeoff: compilers trade build time for runtime speed, interpreters trade runtime speed for instant feedback. The two approaches are complementary, not competing.
