## Question
In plain English: what does it mean for a vector v to be an eigenvector of a matrix A?

## Response
"For vector v to be an eigenvector of a matrix A it means matrix A can only transform that vector in one way... which is scaling it along the direction in which it already points."

## Evaluation
Exactly right. Eigenvectors are directions that the matrix only stretches/shrinks, never rotates.
