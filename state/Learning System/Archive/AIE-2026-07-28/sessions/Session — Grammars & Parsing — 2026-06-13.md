## Key Distinctions Covered

- **Lexical grammar** (character-level, regular language) → implemented by the scanner/lexer → produces tokens
- **Syntactic grammar** (token-level, context-free) → implemented by the parser → produces syntax tree/AST
- CFGs use recursive production rules to handle deeply nested structures that regular languages cannot
- Formal grammar concept bridges both levels (Chomsky hierarchy)
