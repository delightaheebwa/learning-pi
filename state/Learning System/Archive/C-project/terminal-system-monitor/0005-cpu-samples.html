Lesson 05 / Computation + Systems

Measure change, not a snapshot.

CPU usage is not stored as a ready-made percentage. Linux gives us cumulative time counters. Read them twice, subtract, and turn the work done during the interval into a percentage.

Estimated time: 75-120 minutes · Prerequisites: Lesson 4

The counter line

The first line of /proc/stat begins with cpu and then gives cumulative USER_HZ counters:

cpu  100 0 20 80 0 0 0 0 0 0

For this course, group them as:

\[\mathrm{busy} = \mathrm{user} + \mathrm{nice} + \mathrm{system} + \mathrm{irq} + \mathrm{softirq} + \mathrm{steal}\]

\[\mathrm{idleBucket} = \mathrm{idle} + \mathrm{iowait}\]

\[\mathrm{total} = \mathrm{busy} + \mathrm{idleBucket}\]

Then calculate:

\[\mathrm{CPU\%} = 100 \times \frac{\Delta\mathrm{busy}}{\Delta\mathrm{total}}\]

The guest counters are already included in user and nice; adding them again would count the same time twice.

Parse the aggregate line

struct cpu_times {
    unsigned long long user;
    unsigned long long nice;
    unsigned long long system;
    unsigned long long idle;
    unsigned long long iowait;
    unsigned long long irq;
    unsigned long long softirq;
    unsigned long long steal;
};

int parse_cpu_line(const char *line, struct cpu_times *out)
{
    return sscanf(line, "cpu %llu %llu %llu %llu %llu %llu %llu %llu",
                  &out->user, &out->nice, &out->system, &out->idle,
                  &out->iowait, &out->irq, &out->softirq, &out->steal) == 8
           ? 0 : -1;
}

Test the parser with two fixture lines. Use simple numbers where the expected answer is obvious: an earlier total of 200, a later total of 300, and 50 more busy ticks means 50% busy.

Take two live readings

static unsigned long long busy(struct cpu_times t)
{
    return t.user + t.nice + t.system + t.irq + t.softirq + t.steal;
}

static unsigned long long total(struct cpu_times t)
{
    return busy(t) + t.idle + t.iowait;
}

double cpu_percent(struct cpu_times before, struct cpu_times now)
{
    unsigned long long busy_before = busy(before);
    unsigned long long busy_now = busy(now);
    unsigned long long total_before = total(before);
    unsigned long long total_now = total(now);

    /* A counter regression means the two samples cannot be compared. */
    if (busy_now < busy_before || total_now < total_before) return 0.0;

    unsigned long long busy_delta = busy_now - busy_before;
    unsigned long long total_delta = total_now - total_before;
    if (total_delta == 0) return 0.0;
    return 100.0 * busy_delta / total_delta;
}

Read once, wait roughly one second, read again, then call cpu_percent. The dashboard will repeat this process on every refresh.
