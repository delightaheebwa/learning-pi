Lesson 03 / Tests + Abstraction

Test the text, not the machine.

Linux changes while your program runs. A fixture does not. We will make the memory parser a pure function, then give it controlled text and a real test runner.

Estimated time: 60-90 minutes · Prerequisites: Lesson 2

The seam

Keep these responsibilities separate:

int read_meminfo(const char *path, struct memory *out);
int parse_meminfo(const char *text, struct memory *out);

The first function opens a file. The second interprets text. The second is where most bugs live, so it is where most unit tests belong.

Give the project a shape

Lesson 1 started with one file. Now make the boundaries visible. Run these commands from the monitor directory:

mkdir -p src tests/fixtures third_party
mv main.c src/main.c
curl -fsSL \
  https://raw.githubusercontent.com/mity/acutest/master/include/acutest.h \
  -o third_party/acutest.h

The header is vendored into this learning project, not linked as a system library. That keeps the test command reproducible on a machine with only a C compiler.

Start with a failing test

The official Acutest header provides the runner. It is a single-header dependency; no library installation or linker flag is required.

First declare the data shape in src/meminfo.h:

#ifndef MEMINFO_H
#define MEMINFO_H

struct memory {
    unsigned long total_kb;
    unsigned long available_kb;
};

int parse_meminfo(const char *text, struct memory *out);

#endif
#include "acutest.h"
#include "meminfo.h"

static void test_parses_memory_totals(void)
{
    const char *input =
        "MemTotal:       1000 kB\n"
        "MemAvailable:    400 kB\n";
    struct memory memory = {0};

    TEST_CHECK(parse_meminfo(input, &memory) == 0);
    TEST_CHECK(memory.total_kb == 1000);
    TEST_CHECK(memory.available_kb == 400);
}

TEST_LIST = {
    { "parses memory totals", test_parses_memory_totals },
    { NULL, NULL }
};

Save the test above as tests/test_meminfo.c.

At first, parse_meminfo does not exist. That is a useful failure: the test describes the interface we want before implementation details distract us.

Give the test the smallest implementation

One simple implementation can scan each line for a key and a number. You can improve its error handling later; for now, make the first fixture pass. This first version only checks that a total was found; the next test will expose that limitation.

#include "meminfo.h"
#include <stdio.h>
#include <string.h>

int parse_meminfo(const char *text, struct memory *out)
{
    char key[32];
    unsigned long value;
    const char *line = text;

    while (sscanf(line, "%31[^:]: %lu", key, &value) == 2) {
        if (strcmp(key, "MemTotal") == 0) out->total_kb = value;
        if (strcmp(key, "MemAvailable") == 0) out->available_kb = value;

        line = strchr(line, '\n');
        if (line == NULL) break;
        line++;
    }

    return out->total_kb != 0 ? 0 : -1;
}

Save the implementation below as src/meminfo.c. Compile the test by linking the test file with the module under test. The -Isrc flag is what lets #include "meminfo.h" resolve:

cc -Wall -Wextra -std=c17 -g -Ithird_party \
    -Isrc tests/test_meminfo.c src/meminfo.c -o tests/test_meminfo
./tests/test_meminfo

# The Makefile below runs the same command:
make test

Make the test command repeatable

Replace the Lesson 1 Makefile with this version:

CC = gcc
CPPFLAGS = -Isrc -Ithird_party
CFLAGS = -Wall -Wextra -std=c17 -g

monitor: src/main.c src/meminfo.c src/meminfo.h
	$(CC) $(CPPFLAGS) $(CFLAGS) src/main.c src/meminfo.c -o $@

tests/test_meminfo: tests/test_meminfo.c src/meminfo.c src/meminfo.h third_party/acutest.h
	$(CC) $(CPPFLAGS) $(CFLAGS) tests/test_meminfo.c src/meminfo.c -o $@

test: tests/test_meminfo
	./tests/test_meminfo

clean:
	rm -f monitor tests/test_meminfo

.PHONY: test clean

The test target depends on the test executable, so make test rebuilds it only when its source or headers change.

Practice: add one rule

Add a test for a missing MemAvailable line and assert that parsing returns an error. The starter implementation only checks MemTotal, so this test should go red. Then change the return condition to require both fields and run make test again.
