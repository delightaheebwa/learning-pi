Lesson 07 / Interaction

Give the monitor a heartbeat.

The data layers work. Now turn them into a terminal application: enter a controlled input mode, redraw the same screen, respond to q, and always return the terminal to its original state.

Terminal state is borrowed state

Canonical input normally waits for Enter. A dashboard needs a short read timeout so it can refresh even when no key is pressed. Save the original settings before changing them, and register cleanup immediately.

#include <signal.h>
#include <stdio.h>
#include <stdlib.h>
#include <termios.h>
#include <unistd.h>

static struct termios original_terminal;
static volatile sig_atomic_t stop_requested = 0;

static void restore_terminal(void)
{
    tcsetattr(STDIN_FILENO, TCSAFLUSH, &original_terminal);
    fputs("\x1b[?25h\x1b[0m\n", stdout);
}

static void enter_dashboard_mode(void)
{
    tcgetattr(STDIN_FILENO, &original_terminal);
    atexit(restore_terminal);

    struct termios raw = original_terminal;
    raw.c_lflag &= ~(ECHO | ICANON);
    raw.c_cc[VMIN] = 0;
    raw.c_cc[VTIME] = 1; /* 100 ms read timeout */
    tcsetattr(STDIN_FILENO, TCSAFLUSH, &raw);
}

This is a deliberately small raw-mode subset. The termios reference and kilo tutorial explain the flags in more detail.

Handle Ctrl-C safely

A signal handler should do very little. Set a flag; let the ordinary control flow perform cleanup. This avoids calling complex, non-async-signal-safe functions from the handler.

#include <signal.h>

static void handle_sigint(int signal_number)
{
    (void)signal_number;
    stop_requested = 1;
}

static void install_signal_handler(void)
{
    struct sigaction action = {0};
    action.sa_handler = handle_sigint;
    sigemptyset(&action.sa_mask);
    sigaction(SIGINT, &action, NULL);
}

Bridge the data modules

Lesson 5 taught the pure parse_cpu_line function. This thin wrapper reads the first line of /proc/stat, which is the aggregate cpu line, and hands it to the parser. The memory display is another small helper built from Lesson 4.

static int read_cpu_times(const char *path, struct cpu_times *out)
{
    FILE *file = fopen(path, "r");
    if (file == NULL) return -1;

    char line[256];
    if (fgets(line, sizeof(line), file) == NULL) {
        fclose(file);
        return -1;
    }
    fclose(file);
    return parse_cpu_line(line, out);
}

static void print_memory(struct memory memory)
{
    if (memory.total_kb == 0 || memory.available_kb > memory.total_kb) {
        puts("RAM: unavailable");
        return;
    }

    unsigned long used_kb = memory.total_kb - memory.available_kb;
    double percent = 100.0 * used_kb / memory.total_kb;
    printf("RAM: %lu / %lu kB (%5.1f%% used)\n",
           used_kb, memory.total_kb, percent);
}

Redraw, then wait

Use the ANSI sequences from the reference sheet to erase the old frame and move home. The \x1b[?25l sequence hides the cursor while drawing; the registered cleanup shows it again.

int main(void)
{
    enter_dashboard_mode();
    install_signal_handler();

    while (!stop_requested) {
        struct memory memory = {0};
        struct cpu_times before = {0};
        struct cpu_times now = {0};

        if (read_meminfo("/proc/meminfo", &memory) != 0 ||
            read_cpu_times("/proc/stat", &before) != 0) {
            fputs("could not read system metrics\n", stderr);
            return 1;
        }
        sleep(1);
        if (read_cpu_times("/proc/stat", &now) != 0) {
            fputs("could not read CPU metrics\n", stderr);
            return 1;
        }

        fputs("\x1b[2J\x1b[H\x1b[?25l", stdout);
        printf("mini-monitor\nCPU: %5.1f%%\n", cpu_percent(before, now));
        print_memory(memory);
        puts("\nPID      NAME");
        print_processes();
        fflush(stdout);

        char key;
        if (read(STDIN_FILENO, &key, 1) == 1 && key == 'q') {
            stop_requested = 1;
        }
    }
    return 0; /* returning runs restore_terminal via atexit */
}

The first version can redraw the whole screen. Later, an append buffer or ncurses can reduce flicker and handle terminal capabilities more portably.

Practice: finish and stress the exit path

  1. Run the monitor from a normal terminal.
  2. Quit with q; run echo shell restored afterward.
  3. Run it again and quit with Ctrl-C.
  4. Start and stop it repeatedly. The cursor and shell echo should always return.

If the terminal is left in a strange state, type reset and inspect which cleanup path was skipped.
