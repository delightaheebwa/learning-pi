Make the machine say hello.

Before we read Linux internals or draw a dashboard, we need a tiny, repeatable build. Your win is not "hello world"; it is knowing exactly how source code becomes a runnable program.

One small mental model

A C project begins as text. The compiler translates each .c file into machine-code-like object code; the linker combines object code with libraries to make an executable. For this first step, gcc can invoke both stages for us.

Then make records the recipe. It is not a compiler. It is a small build tool that checks prerequisites and runs commands when a target is out of date.

Connection to the mission. A live system monitor will eventually have several source files and test binaries. A reliable build is the first piece of process discipline that keeps those parts understandable.

Build it

Work in a new directory for the monitor. Type the source rather than pasting it; the point is to notice the punctuation and the compiler's response.

mkdir -p monitor
cd monitor
touch main.c
${EDITOR:-vi} main.c

Put this in main.c:

#include <stdio.h>

int main(void)
{
    puts("terminal system monitor: starting");
    return 0;
}

Compile with warnings enabled, then run the result:

gcc -Wall -Wextra -std=c17 -g main.c -o monitor
./monitor

You should see:

terminal system monitor: starting

Make the recipe repeatable

Create a file named Makefile beside main.c:

CC = gcc
CFLAGS = -Wall -Wextra -std=c17 -g

monitor: main.c
	$(CC) $(CFLAGS) main.c -o monitor

clean:
	rm -f monitor

.PHONY: clean

The indentation before $(CC) and rm must be a tab. The target monitor depends on main.c. If the source has not changed, make can avoid repeating work.

make
./monitor
make clean
make

Practice: make one deliberate change

  1. Change the message to include your own monitor name.
  2. Run make and observe the compile command.
  3. Run make a second time. What does it do differently?
  4. Run make clean, then make again. Why must compilation happen now?

Write down one sentence answering: "What is the relationship between main.c, the target monitor, and the recipe?"
