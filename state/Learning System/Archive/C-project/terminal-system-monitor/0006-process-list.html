Lesson 06 / Interaction + Systems

Walk the process tree's front door.

Linux exposes each process as a numeric directory under /proc. Scan those directories, reject everything that is not a PID, and read a friendly name for each surviving entry.

Numeric directories are the boundary

A directory listing can contain self, thread-self, and other kernel entries. A process directory has a name made entirely of digits. Test that predicate separately:

#include <ctype.h>
#include <stdbool.h>

bool is_pid_name(const char *name)
{
    if (*name == '\0') return false;
    for (const char *cursor = name; *cursor != '\0'; cursor++) {
        if (!isdigit((unsigned char)*cursor)) return false;
    }
    return true;
}

Do not call atoi first and use zero to mean "not a PID"; validating the string makes the boundary explicit and avoids accidental acceptance of partial input.

Read one process name

The comm file is simpler than stat for the first version. It contains the task name followed by a newline:

#include <stdio.h>
#include <string.h>

int read_process_name(const char *pid, char *name, size_t capacity)
{
    char path[64];
    snprintf(path, sizeof(path), "/proc/%s/comm", pid);

    FILE *file = fopen(path, "r");
    if (file == NULL) return -1;
    if (fgets(name, capacity, file) == NULL) {
        fclose(file);
        return -1;
    }
    fclose(file);

    name[strcspn(name, "\n")] = '\0';
    return 0;
}

Linux limits this name to 15 visible characters because TASK_COMM_LEN is 16 bytes including the terminator. That is why a long name may be shorter here than in ps; the later stat stretch gives you more context.

Scan the directory

#include <dirent.h>

void print_processes(void)
{
    DIR *proc = opendir("/proc");
    if (proc == NULL) return;

    struct dirent *entry;
    while ((entry = readdir(proc)) != NULL) {
        if (!is_pid_name(entry->d_name)) continue;

        char name[256];
        if (read_process_name(entry->d_name, name, sizeof(name)) == 0) {
            printf("%-8s %s\n", entry->d_name, name);
        }
    }
    closedir(proc);
}

Processes can exit between readdir and fopen. That is normal. Skip entries that disappear instead of treating the race as a fatal program error.

Practice: test the boundary

Add Acutest cases for "1", "12345", "self", the empty string, and "12x". Then run the program and compare a few rows with ps.

Stretch: switch from comm to stat and parse the executable name. Remember that the name is enclosed in parentheses and can contain spaces.
