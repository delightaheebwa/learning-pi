Live files are interfaces

/proc/meminfo looks like a text file, but it is a kernel-provided interface. It may contain more fields than you need, and its values change between reads. Treat it like an external input: check whether opening and reading succeeded.

MemTotal:       16384256 kB
MemFree:         1234567 kB
MemAvailable:    9123456 kB
Buffers:          123456 kB

For the MVP, use MemTotal and MemAvailable. "Available" is more useful than "free" for a dashboard because it includes memory the kernel estimates it can reclaim without swapping.

Thin I/O glue

Keep file handling separate from parsing. This helper reads a complete file into a caller-owned buffer:

#include <stdio.h>
#include <stdlib.h>

static char *read_file(const char *path)
{
    FILE *file = fopen(path, "r");
    if (file == NULL) return NULL;

    /* procfs streams are not ordinary seekable files. */
    size_t capacity = 4096;
    size_t length = 0;
    char *text = malloc(capacity);
    if (text == NULL) { fclose(file); return NULL; }

    for (;;) {
        if (length + 1 == capacity) {
            capacity *= 2;
            char *grown = realloc(text, capacity);
            if (grown == NULL) { free(text); fclose(file); return NULL; }
            text = grown;
        }

        size_t bytes = fread(text + length, 1, capacity - length - 1, file);
        length += bytes;
        if (bytes == 0) break;
    }
    int failed = ferror(file);
    fclose(file);
    if (failed) { free(text); return NULL; }

    text[length] = '\0';
    return text;
}

The production wrapper can now be small:

int read_meminfo(const char *path, struct memory *out)
{
    char *text = read_file(path);
    if (text == NULL) return -1;

    int status = parse_meminfo(text, out);
    free(text);
    return status;
}

/* In main(): */
struct memory memory = {0};
if (read_meminfo("/proc/meminfo", &memory) != 0) {
    fputs("could not read memory information\n", stderr);
    return 1;
}

Turn values into a useful display

/* inside main() */
if (memory.total_kb == 0 || memory.available_kb > memory.total_kb) {
    fputs("invalid memory totals\n", stderr);
    return 1;
}

unsigned long used_kb = memory.total_kb - memory.available_kb;
double used_percent = 100.0 * used_kb / memory.total_kb;

printf("RAM: %lu / %lu kB (%5.1f%% used)\n",
       used_kb, memory.total_kb, used_percent);

Validate the counters before subtracting or dividing: both values are in kB, the total must be nonzero, and available memory should not exceed total memory.

Practice: add a smoke test

Keep the parser tests fixture-based. Add one small executable or test function that calls read_meminfo("/proc/meminfo", &memory) and checks that the total is positive and available memory is no greater than total memory. This is a smoke test, not a brittle exact-value test.
