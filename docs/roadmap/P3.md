## P3.1 — Repurpose the judge for disputes only
- **Problem:** the judge is a general second LLM; "more verification" is not "better verification."
- **Do:** keep the deterministic path as primary; use the judge only for the concrete dispute case
  (the same issue blocking repeatedly) and for genuine semantic tie-breaks, not as a blanket check.
  Document the boundary.
- **Files:** `.pi/extensions/learning-gate/gate-core/judge/*`, `contracts/learning-core.json`,
  `CONTRACT.md`.
- **Verify:** existing judge tests still pass; a test that the judge is not consulted on ordinary
  passes.

## P3.2 — Instrument `viz` ROI or demote it
- **Problem:** the `viz` subsystem is real complexity with unclear learning value.
- **Do:** either add a minimal attribution signal (when a `[[TURN:viz]]` figure is followed by correct
  application vs not) and a report, or demote `viz` to opt-in-only and document why. Pick one and be
  explicit.
- **Files:** `.pi/skills/learning-viz/SKILL.md`, `.pi/extensions/viz-mode/*` (only if instrumenting),
  `AUDIT-ROADMAP.md`.
- **Verify:** doc/behavior; `learn-check` passes.

## P3.3 — Learning analytics
- **Problem:** no aggregate view of the learner's cognitive-health trend.
- **Do:** add `ops.py analytics [TRACK] [--json]` reporting independence trend (solo results), hint
  debt, confidence calibration, mastery dimension mix, and retention/regression counts. Keep it
  read-only and derived from `Attempts.json`.
- **Files:** `learning-system/scripts/ops.py`, `scripts/ops_test.py`.
- **Verify:** `ops_test.py` for the analytics computation on a synthetic history.

## P3.4 — Learner challenge / dispute workflow
- **Problem:** the learner cannot formally contest a stored claim.
- **Do:** define a workflow (skill + optionally a `docs` note) where the learner flags a wiki claim or
  a grade; the system re-verifies against the cited source and, if wrong, corrects the page (marking
  dependents `unverified` per the P0.6 convention) and records the correction. No new gate is
  required; keep it a documented procedure with evidence.
- **Files:** `.pi/skills/llm-wiki/SKILL.md`, `.pi/skills/learning-system/SKILL.md`,
  `Knowledge Wiki/AGENTS.md`.
- **Verify:** doc/behavior.
